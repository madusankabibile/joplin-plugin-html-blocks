## Reporting a Vulnerability

We take the security of `joplin-plugin-html-blocks` seriously. If you discover a security vulnerability within this project, please report it responsibly using the guidelines below.

### Where to Report

Please **do not** report security vulnerabilities through public GitHub issues, pull requests, or discussions, as this can expose users to risk before a fix is available. Instead, please report them via one of the following methods:

* **Private Vulnerability Reporting:** Use the [GitHub Security Advisories](https://github.com/madusankabibile/joplin-plugin-html-blocks/security/advisories/new) tab in this repository to privately disclose the issue.
* **Direct Contact:** You can reach out directly to the maintainer via the contact information available on the repository owner's GitHub profile.

### What to Include in Your Report

To help us triage and address the vulnerability as quickly as possible, please provide as much of the following information as you can:

* Type of vulnerability (e.g., Cross-Site Scripting (XSS), arbitrary code execution, etc.).
* Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
* Affected versions of the plugin or Joplin environment details.
* Any potential impact or mitigation ideas you have identified.

### What to Expect

* **Acknowledgment:** You can expect an initial response or acknowledgment of your report within **48 to 72 hours**.
* **Updates:** We will provide regular updates on our progress as we investigate, develop, and test a fix. 
* **Public Disclosure:** Once a patch is developed, tested, and released, a public security advisory will be published detailing the vulnerability, crediting you (if desired), and advising users to upgrade.
